Política de Privacidade

Última atualização: 8 de outubro de 2026

O ClipesMaestro é uma ferramenta de uso pessoal do criador de conteúdo KamusMG, usada apenas para publicar vídeos no canal dele. Esta política explica o que o aplicativo acessa quando o dono do canal o autoriza com a Conta do Google.

Dados que o aplicativo acessa

  • YouTube (escopos youtube.upload e youtube.force-ssl): usados somente para enviar vídeos, definir título, descrição, miniatura, legendas e o horário de publicação no canal do próprio usuário que autorizou.
  • O aplicativo não lê, coleta, vende nem compartilha dados de espectadores, comentários, inscritos ou de qualquer outra pessoa.

Onde os dados ficam

As credenciais de acesso (tokens do Google) ficam guardadas apenas no computador do dono do canal. Nada é enviado para servidores de terceiros além das próprias APIs do Google/YouTube, usadas para publicar os vídeos.

Uso dos dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O ClipesMaestro também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Exclusão de dados

O ClipesMaestro não guarda dados da API do YouTube em servidores. As únicas informações guardadas são as credenciais de acesso (tokens), no computador do próprio usuário. Elas podem ser apagadas a qualquer momento revogando o acesso (abaixo) ou apagando o arquivo de credenciais do aplicativo; ao revogar, o Google invalida os tokens imediatamente. Qualquer dado de API eventualmente mantido em cache é descartado em no máximo 30 dias.

Como revogar o acesso

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions. Ao revogar, as credenciais guardadas deixam de funcionar.
